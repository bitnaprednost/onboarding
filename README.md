# Advent Of Code 2022

This repo includes solutions for [Advent Of Code 2022](https://adventofcode.com/2022).

## Running the solutions

To run the solutions first you need to build the project by calling `./gradlew build` in the terminal.
Then to run the solutions run `java -jar build/libs/onboarding-1.0-SNAPSHOT.jar`

### Tests

This repo also includes tests for the solutions. Tests could be run by calling `./gradlew test`.
Tests are included because they are very useful when refactoring, they make sure all days solutions still function properly.
